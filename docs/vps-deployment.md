# نشر موقع سيجما على VPS

مصدر كود الموقع هو مستودع `ammar7rb/sigma-site`، وفرع النشر هو `main`.
بعد تعديل الكود في `E:\xampp\htdocs\ba` شغّل:

```powershell
git add -A
git commit -m "وصف التعديل"
git push origin main
```

يبدأ GitHub Actions النشر تلقائيًا بعد نجاح `push`. تظهر النتيجة في تبويب
**Actions** بمستودع `sigma-site`. لا يكفي حفظ الملف محليًا وحده.

ينقل النشر ملفات الكود، ثم يشغّل `composer install` وعمليات Laravel الخاصة
بالنشر وقاعدة البيانات، وبعدها يفحص واجهة API. يحافظ على `.env` ومفاتيح
Passport و`storage` وملفات المستخدمين المرفوعة، ولا ينقل قاعدة بيانات XAMPP
إلى قاعدة بيانات الموقع. تغييرات البيانات المحلية تحتاج نقلًا منفصلًا.

إذا فشل النشر، راجع سجل التشغيل في **Actions** قبل إعادة المحاولة. يمكن
إرجاع كود الموقع بإرجاع commit ثم رفعه؛ تغييرات قاعدة البيانات لا ترجع
تلقائيًا مع الكود، لذلك احتفظ بنسخ Hostinger الاحتياطية.
